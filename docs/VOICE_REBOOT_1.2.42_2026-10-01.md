# Voice stall and reboot reported on 1.2.42 (2026-10-01)

The user reported that voice input stopped, the system became unresponsive, and the device appeared to restart. The first read after the report found firmware 1.2.42 at 63 seconds uptime, so a restart had occurred. Bluetooth was connected, no HID modifier or release report remained pending, and the new boot reported zero USB recoveries. A later 6.1-second voice session decoded 396 BLE audio frames and delivered 96,800 USB PCM samples, 83,003 of them nonzero. This confirms post-reboot recovery, not the cause of the preceding failure.

The ordinary log ring is volatile and did not retain the pre-reboot fault. The NVS `persisted_first_audio_fault` has the same endpoint register pattern documented in `USB_INCIDENT_1.2.31_1.2.33.md` (enabled EP3, pending 64-byte transfer, FIFO mask set, `DIEPINT=0x2010`, 35 free FIFO words). It has no date or firmware version and must not be attributed to the 1.2.42 incident. Neither a new USB recovery nor an Alt release failure was observed after reboot. The specific reset cause remains unproven.

The immediate Right Alt change in 1.2.42 did not modify UAC transfer scheduling. It can change when a speech application opens capture, so an interaction remains possible, but the available evidence does not establish one.

Version 1.2.43 adds `boot_reset_reason` and `boot_usb_recovery_restart` to `/api/status` and logs both at boot. A one-shot RTC marker is set immediately before the firmware's deliberate restart after repeated USB audio recovery failure. This will distinguish that containment restart from other reset classes on a future incident. The build passed, OTA returned HTTP 200, and readback confirmed version 1.2.43, BLE connected, Wi-Fi idle timeout restored, no held HID modifier, and zero new USB recoveries. Its first boot reported reset reason 3 and `boot_usb_recovery_restart=false`, as expected for the OTA restart. Read-only post-incident evidence from 1.2.42 is saved under `.cache/incident-20261001-voice-reboot-1.2.42/`.
