默认层长按音量＋ 600 毫秒进入第一层；第一层短按音量＋返回默认层。第一层名称为 Codex，保持现有黄色层颜色，改为持续层，不再空闲 15 秒自动退出。

| 遥控器键 | 第一层功能 | 实际按键 |
| --- | --- | --- |
| 左 | 上一个聊天或标签 | Ctrl+PageUp |
| 右 | 下一个聊天或标签 | Ctrl+PageDown |
| 上／下 | 当前控件导航 | 上／下箭头 |
| 开关机 | 完全继承默认层 | 单击 Esc；长按现有电源动作 |
| 确认 | 完全继承默认层 | 单击 Enter；双击 Ctrl+V |
| 返回 | 完全继承默认层 | 按住 Backspace |
| 主页 | 切换聊天与右侧标签面板 | Ctrl+Alt+B |
| 菜单 | 显示／隐藏左侧栏 | Ctrl+B |
| 电视 | 打开代码审查 | Ctrl+Shift+G |
| 音量＋ | 返回默认层 | 层切换，无 HID 按键 |
| 语音 | 沿用默认层的实时长按语音输入 | 现有 Right Alt 语音映射 |

新增组合键均配置为键盘 TAP，发送后自动释放。开关机、确认、返回在第一层不设覆盖绑定，始终继承默认层配置及其后续修改。主页和菜单的默认附带手势仍使用空动作覆盖，双击空动作窗口为 1 毫秒。

快捷键核对来源：[OpenAI 官方 Windows 快捷键文档](https://learn.chatgpt.com/docs/reference/commands)。聊天／标签切换由 Codex 当前焦点决定，右侧标签有焦点时可能切换标签。Enter 操作当前焦点控件，审批框有焦点时可能确认审批；并非独立的“发送消息”命令。上下箭头也由当前焦点决定，输入框为空时上箭头可能恢复上一条提示。
