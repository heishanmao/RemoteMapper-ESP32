# 现有页面：系统设置、备份与日志整理

用户决定沿用原页面的样式与主体布局，不采用此前的整体改版。
本轮只整理原「配置管理」「Wi-Fi 与系统配置」「运行日志」三个入口。
首页状态卡、遥控器与改键测试、蓝牙配对管理保留原结构；Wi-Fi 状态卡保留紧凑的空闲休眠开关。

## 三个入口与内容顺序

| 入口 | 内容归属与顺序 |
| --- | --- |
| 备份与恢复 | 按键映射/层级导入导出 → 脱敏与完整系统备份 → 从文件恢复 → 页末出厂重置 |
| 系统设置 | 左右两栏连续展示，Wi-Fi 与配网、AP 热点配置分别成卡，不设子导航或子页 |
| 诊断与日志 | 运行日志 → 默认折叠的高级诊断（只读 NVS、GATT 探测） |

主导航仍有五个入口，默认打开原「遥控器与改键测试」。不新增概览页。

### 首页蓝牙卡片与配对页

用户撤回蓝牙信息集中展示方案，恢复此前的紧凑首页蓝牙状态卡，显示连接状态、名称和电量。
蓝牙配对页恢复原有物理连接、电量、绑定目标与本体信息，以及全部配对操作。
Wi-Fi 小开关位置、Wi-Fi 与 AP 两张独立卡片及其他已确认的页面整理保留。

### 系统设置

系统设置仅一个页面，桌面端使用左右两栏：

- 左栏：两张独立卡片，「Wi-Fi 与配网」（路由器连接）→「AP 热点配置」，卡片间有明确间隔。
- 右栏：可靠性保护 → OTA 升级 → 重启。

各栏直接向下滚动，不设子导航、隐藏分类或二次页面切换。768 px 以下自动变为单栏。

Wi-Fi 空闲节能只在顶部四张状态卡中的 Wi-Fi 卡展示「空闲休眠」小开关，
与已连接 Wi-Fi 名称同一行、靠右展示；长名称省略并保留悬停提示。
不再单独占用系统设置区域。开关立即生效，沿用设备已有的休眠时长。

顶部 Wi-Fi 卡不再单独显示标题，固定三行：SSID 与右侧空闲休眠 → IP 地址 →
热点状态与域名访问。信号强度放入 SSID 悬停提示，热点省电状态简写为「热点已省电」。

### 备份与恢复

集中管理配置备份、文件恢复及出厂重置。按键文件不包含网络/蓝牙；整机配置文件覆盖原支持的网络、
热点、节能、保护与按键参数，恢复后重启。脱敏备份不能恢复密码；蓝牙配对密钥
不能通过配置文件迁移。原参数接口和恢复确认保持原语义。

按键重置仅在原按键测试页保留恢复默认按钮，
共用已有的按键重置流程。整机出厂重置放在备份页末，独立显示清空范围，
保留原确认流程；文件恢复与清空配置分别说明。只读 NVS 查看移入诊断页。

### 诊断与日志

日志支持刷新、复制、导出、清空，新增自动刷新开关。仅日志页和浏览器都可见、
且自动刷新开启时定时请求；进入日志页时仍读取一次，手动刷新始终可用。
向上阅读旧日志时保留滚动位置，位于底部时继续跟随新日志。

高级诊断默认折叠。展开高级区不启动 GATT，展开 NVS 区才按需加载只读快照。
GATT 仍由用户手动开关，结果归本页日志；不再放到网络设置中。
